## Failures found and resolved

- Empty Claude settings sources disabled project slash-skill discovery. The harness now preserves project settings.
- Early coordinators guessed the pack layout, duplicated reviews or inherited recursive delegation instructions. The skill now states the actual layout, bounded-packet behavior and eligible coordinator review rule.
- A Claude child edited correctly but could not run its Bash checks under `acceptEdits` alone. Frontier checks supplied the missing evidence; the host guide now requires task-scoped permissions for already-authorized child verification.
- Both initial UI runs reached correct artifacts but hit the 240-second harness cap before receipt writing. Their failures remain recorded. Browser review was captured against exact artifact hashes, and frontier completion saved accepted receipts. A Codex resume initially defaulted to read-only; explicitly restoring workspace-write completed the receipt. Future UI/project harness limits are 360/480 seconds. These are recovered, assisted completions, not unattended first-pass successes.
- A UI receipt confused pack publication time with task start. Acceptance timing uses the harness clock; the original discrepancy is preserved. Receipt guidance now explicitly requires actual run timestamps and pack candidate/tier identity for the verifier.
