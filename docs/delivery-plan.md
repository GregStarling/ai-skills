# Model Governor v1 delivery

The user corrected excessive orchestration overhead. Build the product directly with disjoint ownership, meaningful tests, and Foreman checkpoint review. Existing source spec remains authoritative; original Foreman history is preserved, not rewritten to claim success.

1. Usable governance core: repaired shared schemas, canonical registry/evidence validation, human policy, risk/review requirements, qualification, paired comparison, cheapest qualified selection, binding validation and built CLI.
2. Native execution: Claude/Codex compilers and real local subprocess receipts, bounded evaluation fixtures/ledger, delegation and independent final-artifact review.
3. Refresh/discovery/shadow: official metadata ingestion, safe paired replay, staged atomic refresh, inert portable skills.
4. V1 proof: meaningful offline suite plus bounded live provider execution, readable usage docs and honestly reported HOLD/unknown states.

Initial lanes: shared schema + identity/evidence; policy/decision/binding engine; append-only ledger + paired statistics. Root owns CLI, integration and verification. Shared helpers have agreed interfaces; implementation lanes may not edit each other. No more checklist-only subtasks. Stop fixing Foreman itself unless a substantive checkpoint cannot otherwise be reviewed.
