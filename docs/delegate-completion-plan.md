## The goal

`skills/delegate/` is a portable, dependency-free skill for Claude Code and Codex. A frontier coordinator uses it to achieve the requested quality with the least total effort through completion: small work is done directly, substantial bounded work goes to a cheaper evidence-backed worker, and a frontier always verifies delegated results. Total effort counts exploration, coordination, context transfer, failed attempts, repairs and verification. The skill never invents evidence, never claims savings it has not measured, and learns conservatively from local outcomes. The maintainer engine in `src/`, `policy/` and `data/` compiles the evidence-qualified routing pack the skill reads. Token usage is a diagnostic; the success criterion is high-quality completed work with less friction for the user.

## Definition of done

1. A direct task costs two helper subprocesses (`start`, `finish`); a delegated task costs three (`start`, `lookup`, `finish`). `lookup` returns a validated answer of about 2 KB (ordered eligible workers with effort, reviewer, scope, review rule, verbatim limitations, gap code) that a differential test proves equal to `src/routing/resolver.ts` for every published route and roster variant.
2. `SKILL.md` is a decision procedure under 6 KB with no governance vocabulary; `pack-format.md` is at most 1.5 KB; `hosts/claude.md` no longer loads as a nested `CLAUDE.md`; `scripts/verify/skills.mjs` enforces vocabulary, `node:`-only imports, link closure and the two safety sentences that must survive the rewrite.
3. The published pack discloses, per acceptance case, which consumer-folder iteration it ran on, and that both UI cases were assisted, with `data/routing/installed-acceptance.json` byte-identical.
4. `docs/validation-status.md` is the single CI-bound current-state index. It states that zero live trials have run on the current folder until that changes. Historical reports are write-once except dated append-only addenda. The PR #5 live-trial artifacts are locally auditable. One folder-digest encoding correlates status, harness results and receipts.
5. The harness can run the same real TypeScript fixture direct and delegated with identical held-out grading, a trace-derived execution ledger (failed launches, rework, helper tail, routing reads), blocked-run classification, sanitized child environments, an enforced execution ceiling and a quality-gate-first win rule, all tested offline.
6. A counted live campaign has produced the first matched direct-vs-delegated evidence, superseded or explicitly re-blocked the pending research and Codex rows, and published results under `docs/evidence/` with `qualification_authority:false`.
7. Scope expansion and the October renewal are decided against those results with counted budgets, in dated archived evidence files, without broadening the Claude medium mechanical stratum, without widening any `routing_pack.v3` literal under an unchanged version label, and with "no evidence supports delegation for this shape" accepted as a legitimate end state. Zero qualified entries are claimed throughout.

## Risks

- If M0.2 slips past the window the provenance recompile costs 3 executions and merges into M5.2; the consumer keeps working on the current pack meanwhile.
- After M0.2 the published pack's `expires_at` overstates validity by up to a week against entry expiry; lookup gates on entries, CI prints both dates, and the guard in M5.2 prevents a repeat.
- Codex account limits blocked the PR #5 trials; M4 schedules Codex work inside one usable window, forbids reruns and reports blocked arms, so Codex-side evidence may end thin, and M5.2's Codex executions need the following window.
- The demotion rule, the learning defaults and the expansion gate are declared defaults, not empirical thresholds; they stay labelled as such.
- Local advice may still rarely fire: 5 supported tasks per option in 30 days under the same host version, class, risk and guidance digest is deliberately conservative.
- Claude Code reports auxiliary Haiku usage without invocation counts, so ceilings count launched executions, not every host-internal call.
- A host without `node` on PATH (possibly the Codex desktop app) cannot run lookup or finish; the grep fallback in `pack-format.md` is the only path there and is weaker.
- Existing tests pin pack composition; M5 changes update them only with the evidence that justifies them.

## Unproven when this plan completes

Whether delegation reduces total effort on the user's real work beyond the few matched pairs run (exploratory, out-of-route, not qualification); whether the measured helper overhead is small enough in real sessions rather than harness trials; whether local advice ever fires in practice; live-web research routing (never authorized here); any reviewer or worker qualification (at least 20 oracle-graded tasks per treatment and stratum remains a separately budgeted program); high and critical risk routes; medium coverage beyond the quantity-default stratum unless M5.6 is funded and its audits pass.

## Explicitly excluded

- Scoring an unsupported comparable receipt as a failure of its own option: it manufactures a preference from missing bookkeeping.
- A shared `routing-core.mjs` imported by `src/routing/resolver.ts`: the verbatim port plus the all-routes differential test gives the same guarantee without making the maintainer depend on the consumer folder.
- `finish` creating the start event at delivery: it zeroes `elapsed_ms` and biases the elapsed-time proxy toward direct.
- The helper launching any model process, including a fresh reviewer.
- A separate `routing-index.json`: lookup answers from the digest-verified pack at call time.
- A weekly CI cron or a hard CI failure on `refresh_after`: a scheduled red build would force a weekly 3-execution preflight or a policy change.
- Adding required fields to `taskEvidenceRecordSchema` or widening the source literals under the v3 label; the v3-to-v4 bump in M5.4 is the only sanctioned wire change.
- Editing any evidence file, validation report, timestamp or receipt in place; rebinding the medium audit to re-observed runs without fresh reviewer executions.
- Fable and Astra admission to all seven classes, or any admission before a fresh calibration on current CLIs; medium routes before the M5.1 gate; any high or critical route.
- Broadening the existing Claude medium mechanical stratum in any way.
- Changing `--ephemeral` or any coordinator launch flag mid-experiment; thread ids are recorded instead.
- Changing policy thresholds or bumping `policy_version`; truncating pack `expires_at` to the last living entry.
- Experiment results under `data/routing`; they live under `docs/evidence` with `qualification_authority:false`.
- Full reviewer or worker qualification; global installation; provider API keys; changes to user provider configuration; remote repository creation; publication beyond normal commits and PRs of this repository; ebay-lego fixtures unless a public-safe harvest is supplied.
