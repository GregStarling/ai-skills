# Paired inference

`comparePaired` accepts raw binary results paired by task, with an explicit cohort, alpha and noninferiority margin. The caller must establish compatible task, harness and treatment identity before constructing the pairs. Duplicate task IDs, mixed cohorts and malformed results are rejected. Empty input yields null statistics and insufficient evidence. For nonempty input, insufficient means the observed confidence bound does not establish the requested noninferiority margin; it is not proof of inferiority.

The exact two-sided McNemar p-value uses the binomial distribution on discordant outcomes, as described by [statsmodels](https://www.statsmodels.org/stable/generated/statsmodels.stats.contingency_tables.mcnemar.html). The quality difference interval subtracts exact [Clopper–Pearson](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats._result_classes.BinomTestResult.proportion_ci.html) bounds for the candidate-only and incumbent-only success proportions. Each of four tails receives alpha/4; the union bound gives simultaneous interval coverage of at least 1-alpha without requiring independent discordance indicators. Independent sampled tasks are assumed. This deliberately conservative interval stays wide for small identical samples. No bootstrap shortcut or minimum sample-size constant manufactures qualification.
