# Claude Code host

Read this file only when running in Claude Code. Discover the active Agent tool and available models/efforts from the session; documentation does not prove account access. Match the exact pack treatment. Use its explicit model control and a supported effort control or existing matching native agent definition. If the current tool surface cannot express or verify a material setting, exclude that route. Do not silently inherit another model or approximate an alias/effort pair.

Check effective settings: native model precedence and substitution behavior vary by version. Available-model restrictions or environment overrides may change the requested route. If a substitution occurs, record it and choose another eligible route rather than count it as the original treatment. Do not alter global user configuration. Use existing host authentication; cross-provider CLI delegation is optional and requires an already-authorized, authenticated bridge.

Skills can be discovered under `.claude/skills/delegate/` for a project or `~/.claude/skills/delegate/` for personal use and invoked as `/delegate`. Installation must copy the complete folder, including the routing pack and references. This repository's source location is intentionally inert.

Sources checked 2026-09-10: [Claude skills](https://code.claude.com/docs/en/skills), [native subagents and effective model/effort controls](https://code.claude.com/docs/en/sub-agents). Follow the active host's schema when its capabilities differ from current documentation.
